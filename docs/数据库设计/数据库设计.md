# 数据库设计

## 1. 选型与通用约定

- 数据库：MySQL 8.0（8.0.29+）。
- 连接串由环境变量 `DATABASE_URL` 提供，也可由启动参数 `--database-url` 传入，命令行优先于环境变量。
- 迁移在服务启动时自动执行；第一版仅包含 `migrations/0001_init.sql`，后续版本再按序追加迁移，禁止修改已发布迁移。

### 1.1 对象命名约定

所有数据库对象按三类前缀命名：

| 前缀 | 类别 | 说明 |
| --- | --- | --- |
| `b_` | 业务表 | 保存业务主数据与流水底表，物理表 |
| `r_` | 关系表 | 多对多映射与权限表，物理表 |
| `v_` | 视图 | 只读 SQL 视图，跨分表合并、字段裁剪、脱敏与关联展示 |

### 1.2 通用字段约定

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED AUTO_INCREMENT | 非空 | 主键 |
| created_at | DATETIME(3) | 非空 | 创建时间，默认 CURRENT_TIMESTAMP(3) |
| updated_at | DATETIME(3) | 非空 | 更新时间，默认 CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3) |

- 时间统一 `DATETIME(3)` 存 UTC，序列化到 API 时带 `Z`，展示层转 Asia/Shanghai。
- 布尔用 `TINYINT(1)`（即 BOOLEAN）。
- JSON 字段用 MySQL 原生 `JSON` 类型，读取时映射为 serde 的 `serde_json::Value`。
- 长文本：脚本内容、过滤后的执行输出用 `LONGTEXT`；描述类用 `TEXT`。
- 令牌类敏感字段（供应商 access_token）**存储前加密**（AES）。密码加盐哈希：前端 `sha1(密码)` 一次不加盐，后端存 `sha1(salt + 前端值)`，盐为每用户随机 16 字节（hex 32 字符），改密时重生成。

## 2. 用户与认证

### 2.1 b_users 用户表

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED PK | 非空 | 用户 ID |
| email | VARCHAR(255) | 非空 | 登录邮箱 |
| name | VARCHAR(128) | 非空 | 显示名，仅用于展示，不作为登录标识 |
| password | CHAR(40) | 非空 | sha1(salt + 前端 SHA-1 值) |
| password_salt | CHAR(32) | 非空 | 每用户随机盐（16 字节 hex），改密时重生成 |
| is_admin | TINYINT(1) | 非空 | 是否管理员，默认 0 |
| banned_at | DATETIME(3) NULL | 可空 | 禁用时间（封禁生效时刻） |
| unban_at | DATETIME(3) NULL | 可空 | 解禁时间 |
| session_token | TEXT NULL | 可空 | 登录 Token（JWT），单会话，退出时清空 |
| session_expire_at | DATETIME(3) NULL | 可空 | 登录 Token 过期时间，默认 7 天 |
| created_by | BIGINT UNSIGNED NULL | 可空 | 创建人 |
| created_at | DATETIME(3) | 非空 | 创建时间 |

索引：`ux_users_email`（唯一）。

封禁规则：失败次数不落在用户表，改为查 `b_user_operation_logs` 中该用户 `type=login` 且 `status=failed` 的近 5 分钟记录；累计 5 次 → 写 `banned_at=now()`、`unban_at=now()+30min`，返回「已封禁」。到达 `unban_at` 后自动视为解禁（判定时比较当前时间，不靠后台任务清字段）。

### 2.2 b_access_tokens 访问令牌表

用于机器调用（MCP / 第三方 Agent）的长期令牌，与 `b_users.session_token` 分离。撤销方式为置 `disabled_at`。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED PK | 非空 | 令牌 ID |
| user_id | BIGINT UNSIGNED FK b_users | 非空 | 所属用户 |
| name | VARCHAR(128) NULL | 可空 | 令牌备注名 |
| token | VARCHAR(512) | 非空 | JWT 编码字符串，含 `user_id`、`exp`、`jti`，全表唯一 |
| expires_at | DATETIME(3) NULL | 可空 | 过期时间，空表示不过期 |
| disabled_at | DATETIME(3) NULL | 可空 | 禁用时间，非空即撤销 |
| created_at | DATETIME(3) | 非空 | 创建时间 |

索引：`ux_access_tokens_token`（唯一）、`idx_access_tokens_user`（`user_id`）。

校验顺序：JWT 签名与 exp → 按 `token` 查库确认未禁用、未过期。

配额统计窗口：自然日、自然周（周一 00:00）、自然月。请求完成后把本次消耗累加到命中记录的 used 字段（多条命中时累加到 `model_id` 或 `provider_id` 最具体的一条），并更新对应 `*_token_refreshed_at`；到达刷新时间后清零已用量并更新刷新时间，额度判断直接读权限表，不再聚合 `b_request_logs`（日志表仅用于审计与对账）。

### 4.3 b_variables 执行凭据绑定

按项目和环境保存变量别名与可信执行端环境变量名的映射，不挂到具体操作下，也不保存密钥值。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED PK | 非空 | 绑定 ID |
| project_id | BIGINT UNSIGNED FK b_projects | 非空 | 项目 ID |
| environment_id | BIGINT UNSIGNED FK b_environments | 非空 | 必须属于同一项目 |
| key | VARCHAR(128) | 非空 | 项目及环境内的变量别名 |
| source_env | VARCHAR(128) | 非空 | 可信执行端允许读取的环境变量名 |
| description | TEXT NULL | 可空 | 用途说明 |
| disabled_at | DATETIME(3) NULL | 可空 | 禁用时间 |
| created_at | DATETIME(3) | 非空 | 创建时间 |

唯一约束：`(project_id, environment_id, key)`。管理接口只接受部署侧登记的凭据环境变量名，不接受它们的值，也不能引用数据库连接串、签名密钥等服务配置。审核固定绑定 ID 和环境变量名；实际使用前核对仍存在、未禁用且等于审核时的绑定。变更绑定须重新审核，原环境变量名下的密钥轮换不改变绑定。

### 4.4 b_scripts 脚本表

一行表示一个脚本的当前版本。编辑后进入待审核，当前版本重新通过审核才能执行。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED PK | 非空 | 脚本 ID |
| project_id | BIGINT UNSIGNED FK b_projects | 非空 | 项目 ID |
| environment_id | BIGINT UNSIGNED FK b_environments NULL | 可空 | 固定绑定环境，空表示不使用环境凭据 |
| sandbox_id | BIGINT UNSIGNED FK b_sandboxes NULL | 可空 | 指定沙盒，空时仅允许使用项目唯一的沙盒 |
| name | VARCHAR(128) | 非空 | 脚本名称 |
| description | TEXT NULL | 可空 | 描述 |
| type | VARCHAR(32) | 非空 | bash / python |
| content | LONGTEXT | 非空 | 脚本内容，不得硬编码凭据 |
| params | JSON NULL | 可空 | 参数定义，不含密钥和真实调用参数 |
| credential_actions | JSON NULL | 可空 | 申请的预定义操作和凭据绑定 ID；审核通过时固定操作和绑定配置，不含密钥值 |

| created_at | DATETIME(3) | 非空 | 创建时间 |
| updated_by | BIGINT UNSIGNED FK b_users | 非空 | 当前版本编辑者；创建时取创建人 |
| updated_at | DATETIME(3) | 非空 | 编辑时间 |

脚本名在同一项目及绑定环境内唯一，未绑定环境也作为一个唯一性范围。唯一索引使用 `(project_id, COALESCE(environment_id, 0), name)` 的等价表达式，0 仅为索引内部值。环境和沙盒必须属于脚本所在项目。编辑及审核按版本做条件更新，正式执行只能读取已审核的匹配版本。凭据绑定变更使依赖脚本的版本递增并清除原批准，保留脚本最后编辑者，避免借绑定变更绕过独立审核。

| description | TEXT NULL | 可空 | 描述 |

| max_instances | INT UNSIGNED | 非空 | 最大并发容器数，含待清理实例 |
| updated_by | BIGINT UNSIGNED FK b_users | 非空 | 更新人 |
| updated_at | DATETIME(3) | 非空 | 更新时间 |

### 4.7 b_sandbox_instances 沙盒实例表

一条记录对应一次执行的专属容器。容器销毁后保留实例记录用于查询历史。

| 字段 | 类型 | 可空 | 说明 |
| --- | --- | --- | --- |
| id | BIGINT UNSIGNED PK | 非空 | 实例 ID |
| sandbox_id | BIGINT UNSIGNED FK b_sandboxes | 非空 | 所属沙盒配置 |
| name | VARCHAR(128) | 非空 | 服务生成的唯一容器名 |
| status | VARCHAR(16) | 非空 | creating / running / cleaning / cleanup_failed / destroyed |
| created_at | DATETIME(3) | 非空 | 实例记录创建时间 |
| destroyed_at | DATETIME(3) NULL | 可空 | 确认容器已不存在的时间 |

唯一约束：`(name)`。索引：`(sandbox_id, status)`，用于并发准入和待清理查询。实例到达 `destroyed` 才释放并发名额；容器创建失败也要确认容器不存在。实例记录可在关联执行记录到期且实例已销毁后清理。

## 7. 数据保留

- `b_request_logs`、`b_executions`、`b_user_operation_logs` 保留 90 天：按月归档物理表，超期表直接 `DROP TABLE`；视图跨月合并保证查询连续。
- 用户删除规则：若用户仍被任一外键引用（令牌、日志、权限、脚本等），拒绝删除并返回错误；无引用时物理删除。

## 8. MySQL 运维注意

- 视图限制：不能跨库引用，不能引用自身，聚合视图不可更新；MySQL 对视图不做条件下推，条件尽量下推到底表索引。
- 连接池：单实例 `max_connections` 不超过 MySQL `max_connections` 的 1/4，超出时返回 503。
- 慢查询：`b_request_logs` 的聚合查询走 `created_at` 索引，避免大范围扫描导致主从延迟。
- 主从：读流量（日志查询）走只读副本，写走主库；写后立即读需路由到主库。
- 备份：每日全量 + binlog 增量，保留 30 天。
