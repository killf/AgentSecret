# 前端设计

## 1. 技术选型与工程结构

- 技术栈：React 19 + TypeScript + Vite + Ant Design 5 + React Router 7；引入 `@ant-design/v5-patch-for-react-19` 兼容 React 19。
- 请求层：统一 `fetch` 封装（`src/api/client.ts`），自动附加 `Authorization: Bearer <token>`，响应 `code = 2`（未认证/令牌无效）时清除本地 token 并跳登录。
- 目录：

```
src/
  api/            # 按模块拆分的接口封装
  components/     # 通用组件（权限选择器、状态标签、刷新开关、敏感信息提示）
  pages/          # 页面，按路由一一对应
  stores/         # 登录态、全局配置
  utils/          # sha1、时间格式化、脱敏展示
```

- 状态：登录态与用户信息存 `localStorage`；页面数据用组件内状态按需加载，避免为当前页面规模引入全局缓存。

## 2. 登录与鉴权

### 2.1 登录流程

1. 登录页输入邮箱、密码。
2. 前端对密码做 SHA-1（`crypto.subtle.digest('SHA-1')`，注意 `crypto.subtle` 仅在安全上下文可用，需 HTTPS 或 localhost；不可用时引入 `js-sha1` 兜底）。
3. 提交 `{ email, password: sha1(pwd) }`。
4. 成功后保存返回的 JWT 与用户信息，跳转 `/logs`（请求日志）。
5. 失败提示后端返回的 `message`；连续失败由后端按操作日志统计，命中封禁时前端展示剩余封禁时间。

### 2.2 路由守卫

- 未登录访问受保护路由 → 重定向 `/login`。
- 管理员页面（模型管理、供应商管理、用户管理、权限管理、系统设置）在路由元信息上标 `adminOnly`，非管理员跳回首页并提示无权限。
- 前端不做资源级权限的按钮隐藏：列表接口本身按权限过滤，无权限操作后端返回业务码 3，前端统一 toast 提示后端 message。

## 5. 页面详细设计

每页按「布局 / 数据 / 操作表」描述；操作表中的接口均为 `POST /api/v1/` 前缀，省略写为相对路径。

### 5.1 登录页（/login）

- 布局：居中卡片，邮箱、密码输入框与登录按钮。
- 数据：无。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 登录 | 提交 `{ email, password: sha1(pwd) }`；成功保存 JWT 与用户信息并跳 /logs | auth/login |

失败提示后端 message；连续失败命中封禁时展示剩余封禁时间（message 中携带）。

### 5.2 令牌管理页（/tokens）

- 布局：令牌表格 + 右上「新增令牌」按钮。
- 数据：`tokens/list`，列：名称、状态（有效 / 已禁用 / 已过期）、过期时间、创建时间、操作。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增令牌 | 弹窗填名称（可选）与有效期（7 / 30 / 90 天或永不过期）；成功后弹窗一次性展示明文并提供复制按钮 | tokens/add |
| 查看明文 | 详情抽屉展示令牌全量信息与明文，提供复制按钮（明文可随时重新获取） | tokens/detail |
| 禁用 | 二次确认后禁用该令牌 | tokens/disable |
| 启用 | 仅已禁用且未过期的令牌可启用 | tokens/enable |
| 重置 | 二次确认后重新签发，新明文一次性展示，旧令牌立即失效 | tokens/reset |
| 删除 | 二次确认；逻辑删除 | tokens/delete |

### 5.3 请求日志页（/logs）

- 布局：顶部过滤栏 + 自动刷新开关（关闭 / 5 秒 / 30 秒 / 1 分钟，页签不可见时暂停）+ 日志表格 + 分页。
- 数据：`logs/request/list`，过滤条件：日期范围（默认今天，支持今天 / 昨天 / 近 7 天快捷切换）、用户、模型、供应商、状态；列：时间、用户邮箱、模型名、供应商名、状态、输入 / 输出 / 缓存 token、首字耗时、总耗时、敏感标记（命中时行首橙色标记，悬浮提示，不显示命中内容）。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 查看详情 | 详情抽屉展示日志全量字段，`request_detail` / `response_detail` 原文以 JSON 格式化展示 | logs/request/detail |

### 5.4 沙盒日志页（/sandbox-logs）

- 布局：顶部过滤栏 + 执行记录表格 + 分页。
- 数据：`logs/executions/list`，过滤条件：日期范围、项目、环境、脚本、沙盒、沙盒实例、状态；列：开始时间、脚本名、语言、状态、耗时、执行用户、沙盒实例。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 查看详情 | 展示审核版本、起止时间、耗时、固定原因码以及过滤后的 stdout/stderr | logs/executions/detail |

### 5.5 密码设置页（/password）

- 布局：居中表单，旧密码、新密码、确认新密码。
- 数据：无。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 修改密码 | 前端校验：新密码长度 ≥ 8、含字母和数字、与旧密码不同、非弱密码（内置常见密码字典先拦一道，后端再校验）；提交 `{ old_password, new_password }`（均为前端 SHA-1 值） | auth/password |

成功后提示「密码已更新，请重新登录」并跳登录页（后端已清除会话）。

### 5.6 项目与脚本页（/projects）

- 布局：左侧项目列表 + 右侧项目详情（环境 / 凭据绑定 / 脚本 / 沙盒 Tab；凭据绑定仅管理员可见）。
- 数据：`projects/list`，项目列：名称、描述、指导、仓库地址。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增项目 | 弹窗填名称（唯一）、描述、指导、仓库地址数组 | projects/add |
| 编辑项目 | 弹窗改名称 / 描述 / 指导 / 仓库地址 | projects/update |
| 删除项目 | 二次确认；仍被环境 / 凭据绑定 / 脚本 / 执行 / 沙盒 / 权限引用时后端拒绝并提示 | projects/delete |
| 查看详情 | 选中项目后右侧加载详情（`ProjectItem` 全量，含创建时间与状态）并切 Tab | projects/detail |

**环境 Tab**（`environments/list`，列：名称、描述）

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增环境 | 弹窗填名称（项目内唯一）、描述 | environments/add |
| 编辑环境 | 改名称 / 描述；重名后端拒绝 | environments/update |
| 删除环境 | 二次确认；仍被凭据绑定 / 脚本 / 执行 / 权限引用时后端拒绝 | environments/delete |

**凭据绑定 Tab**（仅管理员，`variables/list`）

列：别名、部署侧登记的环境变量名、描述、状态。在选定项目和环境下新增或修改绑定，无需选择操作；页面不接收、不展示密钥值。更改凭据来源、别名或禁用状态会使相关脚本重新待审。

| 操作 | 接口 |
| --- | --- |
| 新增绑定 | variables/add |
| 编辑或禁用绑定 | variables/update |
| 删除绑定 | variables/delete |

**脚本 Tab**（`scripts/list`，列：名称、语言、绑定环境、沙盒、版本、审核状态）

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增、编辑 | 仅管理员，可设置代码、参数、绑定环境、沙盒和凭据操作；保存后进入待审核 | scripts/add、scripts/update |
| 查看脚本 | 可执行用户查看参数定义；管理员可查看源码和凭据操作配置 | scripts/detail |
| 审核 | 另一位管理员核对指定版本，选择通过或驳回；版本已变化时重新加载 | scripts/review |
| 删除 | 仅管理员；仍被执行记录引用时后端拒绝 | scripts/delete |
| 执行 | 仅可执行已审核且有权访问的脚本；只填业务参数，不允许覆盖环境。提交后在沙盒日志查看过滤后的输出 | scripts/run |

**沙盒 Tab**（只读，`sandboxes/list`）

展示名称、白名单镜像和最大并发容器数。`sandboxes/instances` 展示一次性实例的创建、清理和销毁状态；容器销毁后记录仍供审计。

### 5.7 模型管理页（/admin/models）

- 布局：模型表格 + 右上「新增模型」按钮；行展开或抽屉管理供应商关系。
- 数据：`admin/models/list`，列：名称、状态、更新时间。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增模型 | 弹窗填名称（唯一） | admin/models/add |
| 编辑模型 | 改名称；禁用 / 启用（传 `disabled_at` 或 null） | admin/models/update |
| 删除模型 | 二次确认；仍被供应商关系或权限引用时后端拒绝 | admin/models/delete |
| 新增供应商关系 | 弹窗选供应商，填上游模型名、最长输出 / 上下文 token、是否可用 | admin/model-providers/add |
| 编辑供应商关系 | 改上游模型名、输出 / 上下文 token、启用开关 | admin/model-providers/update |
| 删除供应商关系 | 二次确认 | admin/model-providers/delete |
| 测试连通性 | 向上游发最小请求（10 秒超时），展示成功与否、延迟或错误 | admin/model-providers/test |

### 5.8 供应商管理页（/admin/providers）

- 布局：供应商表格 + 右上「新增供应商」按钮。
- 数据：`admin/providers/list`，列：名称、类型（minimax / glm / codex）、base_url、5 小时剩余额度、周剩余额度、额度刷新时间、状态。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增供应商 | 弹窗填名称（唯一）、base_url、访问令牌明文（HTTPS 传输）、类型 | admin/providers/add |
| 编辑供应商 | 改名称 / base_url / 令牌（传值则重新加密）/ 禁用状态 | admin/providers/update |
| 删除供应商 | 二次确认；仍被供应商关系或权限引用时后端拒绝 | admin/providers/delete |
| 刷新额度 | 调上游额度接口并回写 5 小时 / 周剩余额度与刷新时间；失败提示并保留旧值 | admin/providers/refresh-quota |

### 5.9 用户管理页（/admin/users）

- 布局：用户表格（分页）+ 右上「新增用户」按钮；支持按邮箱 / 显示名关键字过滤。
- 数据：`admin/users/list`，列：显示名、邮箱、是否管理员、状态（正常 / 封禁中含解禁时间 / 永久封禁）、最近登录时间、创建时间。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 新增用户 | 弹窗填邮箱（唯一）、显示名、初始密码（前端 SHA-1） | admin/users/add |
| 编辑用户 | 改显示名 / 是否管理员；不能降级最后一个管理员 | admin/users/update |
| 封禁 | 弹窗选永久封禁或时长（默认 30 分钟）；立即下线该用户 | admin/users/ban |
| 解禁 | 清空封禁状态 | admin/users/unban |
| 设置密码 | 直接设置新密码，不校验旧密码 | admin/users/password |
| 删除用户 | 二次确认；仍被令牌 / 日志 / 权限 / 脚本 / 执行引用时后端拒绝 | admin/users/delete |

### 5.10 权限管理页（/admin/permissions）

- 布局：四个 Tab：项目权限、环境权限、模型权限、供应商权限；每个 Tab 一个权限列表。
- 数据：`admin/permissions/list`，列：用户、目标对象（可为「全部」）、限额（模型 / 供应商权限含日 / 周 / 月 token 限额）。
- 操作：

| 操作 | 说明 | 接口 |
| --- | --- | --- |
| 创建 / 更新权限 | 弹窗选用户与目标（「全部」存空），模型 / 供应商权限再填三项限额；同用户 + 目标已存在则更新 | admin/permissions |
| 删除权限 | 二次确认 | admin/permissions/delete |

### 5.11 系统设置页（/admin/settings）

- 布局：设置项只读列表（键、值、描述、更新时间）。
- 数据：`admin/settings/list`。
- 操作：无。写入口后端固定返回 3（无权限），页面不提供任何操作按钮；入口默认隐藏，路由保留。

## 6. 退出登录

- 右上角「退出登录」按钮 → 调用 `POST /api/v1/auth/logout` → 清空本地 token 与用户信息 → `router.push('/login')`。
- 请求失败时也要清除本地状态并跳转，避免残留会话。

## 7. 交互与视觉约定

- 所有列表统一分页（默认 20 条/页）、统一「查询/重置」按钮位置。
- 删除、禁用等破坏性操作一律二次确认。
- 状态用 Tag 颜色统一：成功/正常绿色，禁用灰色，进行中蓝色，失败红色。
- 表格时间列本地时区展示，hover 显示 UTC 原始时间。
