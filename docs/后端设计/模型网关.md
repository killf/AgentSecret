# 模型网关设计

OpenAI 兼容的模型网关，供第三方 Agent / 工具直连调用。与 `/api/v1` 业务接口相互独立：路由前缀 `/v1`、鉴权用访问令牌、错误响应用标准 HTTP 状态码，业务码与 `/api/v1` 同体系（见 §8）。

## 1. 定位与鉴权

- 鉴权：`Authorization: Bearer <access_token>`（`b_access_tokens` 表令牌），与 MCP 使用同一套鉴权链：JWT 验签 → 按 `token` 查库确认未禁用、未过期 → 载入用户与权限；不使用登录会话。
- 与 MCP 的差异仅在客户端场景：网关面向 OpenAI 兼容客户端，MCP 面向 MCP 协议客户端。
- 客户端只需一个地址：OpenAI SDK 的 base_url 配置为 `http://<host>:<port>/v1` 即可。

## 2. 路由

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | /v1/models | 可用模型列表 |
| POST | /v1/responses | 模型调用（OpenAI Responses 格式，支持 stream） |

## 3. 请求链路

```
客户端 → 鉴权 → 权限校验(模型) → 路由选供应商 → 用户配额校验
      → 敏感信息扫描(请求) → 上游代理 → 流式回传 → 敏感信息扫描(响应)
→ 落 `b_request_logs`（底表）→ 累加用户已用配额、扣减供应商剩余额度
```

## 4. 路由选供应商

1. 取该模型下 `enabled=true` 且 `disabled_at IS NULL` 的 `r_model_providers`。
2. 过滤供应商自身禁用与额度耗尽（5 小时/周额度为 0 且未到刷新时间）。
3. 排序策略：优先额度剩余多的，其次 `last_tested_at` 最近的；同分用轮询打散。
4. 命中失败（上游报错/超时）自动切换下一个供应商重试 1 次，仍失败返回 502 并落日志。

路由状态用 `tokio::sync::Mutex` 保护轮询游标，放在进程内。

## 5. 上游代理

- 统一请求（上游适配器内部格式）：`{ model, messages, max_tokens, stream, temperature, ... }`，按 `r_model_providers.model_name` 改写实际模型名；入口请求为 Responses 格式，由各适配器负责转换。
- 统一响应：`{ content, input_tokens, output_tokens, cache_tokens, ttft_ms, duration_ms, raw }`。
- 各厂商差异封装在 `upstream` 子模块的独立适配器中（`minimax.rs`、`glm.rs`、`codex.rs`），对外统一实现 `UpstreamClient` trait，便于新增供应商。
- 流式响应：reqwest 的 `bytes_stream()` 逐块读取，转成 SSE 透传（actix-web 用 `HttpResponse::Ok().streaming(...)` 包装 `BodyStream`），同时累计 token 数与首字时间；命中敏感规则的片段做遮罩后转发。
- 超时：首字 60s，整体 600s，可配置。

## 6. 配额

- 用户维度（`r_model_permissions` / `r_provider_permissions` 的日/周/月限额）：已用量直接读权限表的 `*_token_used` 字段（请求完成后累加），超过阈值直接拒绝，返回 429 并注明超限的限额维度。
- 供应商维度：5 小时窗口与周窗口剩余额度，请求前检查，为 0 则换供应商；到达 `quota_*_refreshed_at` 时调用上游额度查询接口刷新并回写。
- MySQL 无 `RETURNING`，插入后用 `last_insert_id()` 取自增主键；批量写入注意 `max_allowed_packet`。

## 7. 敏感信息过滤

- 规则引擎：正则 + 关键字（AK/SK 开头串、密码/令牌字段、JWT、数据库连接串、内网 IP、手机号、身份证、银行卡等），规则存 `b_system_settings` 的 `security.sensitive_rules`，支持热更新。
- 实现：`security` 模块用 `regex` crate 编译规则集，规则以 `Arc<RegexSet>` 缓存；规则更新时原子替换缓存。
- 请求扫描：命中即在请求体中标记并按策略遮罩（默认遮罩后转发，可配置直接拒绝）。
- 响应扫描：命中则遮罩输出并把 `contains_sensitive` 置 true，同时在 `request_detail` / `response_detail` 中记录遮罩后内容。
- 流式扫描：保留跨块命中能力的滑动缓冲窗口。

## 8. 错误响应

使用标准 HTTP 状态码（OpenAI 兼容必需），响应体为 OpenAI 风格错误结构，`code` 为统一业务码：

| 状态码 | 业务码 | 场景 |
| --- | --- | --- |
| 401 | 2 | 未认证 / 令牌无效或过期 |
| 403 | 3 | 无该模型或供应商权限 |
| 404 | 4 | 模型不存在 |
| 429 | 5 | 用户配额超限 |
| 502 | 6 | 上游失败（重试一次后仍失败） |
| 500 | 7 | 服务端错误 |

```json
{ "error": { "message": "无该模型权限", "type": "permission_error", "code": "3" } }
```

## 9. 接口契约

#### GET /v1/models — 可用模型列表

请求：无。
响应：`GatewayModel[]`。自定义类型 `GatewayModel`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | bigint | 模型 ID |
| name | string | 模型名 |
| max_output_tokens | int | 最长输出 |
| max_context_tokens | int | 最长上下文 |
| providers | GatewayProvider[] | 上游供应商关系 |

自定义类型 `GatewayProvider`：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| provider_id | bigint | 供应商 ID |
| model_name | string | 上游真实模型名 |
| enabled | bool | 关系是否可用 |

执行流程：

```text
rows = query("SELECT m.*, rp.provider_id, rp.model_name, rp.enabled
              FROM b_models m
              LEFT JOIN r_model_providers rp ON rp.model_id = m.id
              WHERE m.disabled_at IS NULL")
if not auth.is_admin:
    allowed = query("SELECT model_id FROM r_model_permissions
                     WHERE user_id = :uid")        // 含 NULL = 全部
    rows = filter_by_model_permission(rows, allowed)
return rows                        // 不含 base_url 与 access_token
```

#### POST /v1/responses — 模型调用

请求：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| model | string | 是 | 模型名 |
| input | string / array | 是 | 输入内容（文本或消息数组，Responses 格式） |
| instructions | string | 否 | 系统级指令 |
| max_output_tokens | int | 否 | 最长输出 |
| temperature | number | 否 | 温度 |
| stream | bool | 否 | 是否流式，默认 false |
| provider | bigint | 否 | 指定供应商（需有权限），空则自动路由 |

响应（非流式，Responses 格式）：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 响应 ID |
| object | string | 固定为 `response` |
| model | string | 模型名 |
| output | array | 输出内容项 |
| usage.input_tokens | int | 输入 token |
| usage.output_tokens | int | 输出 token |
| usage.cache_tokens | int | 缓存 token |
| provider | string | 实际命中的供应商名 |
| ttft_ms | int | 首字耗时 |
| duration_ms | int | 总耗时 |
| contains_sensitive | bool | 是否命中敏感规则 |

流式：Responses 事件流（`text/event-stream`），结束帧附带 usage 统计。
执行流程：

```text
m = query_one("SELECT * FROM b_models WHERE name = :model AND disabled_at IS NULL")
                                                                // 无 → 404
require_model_permission(auth.user, m.id)                       // 无权限 → 403
check_user_quota(auth.user, m.id)                               // 超限 → 429
body = scan_request(:payload)                                   // 命中 → 遮罩或拒绝
p = route_provider(m.id, :provider, auth.user)                  // 见 §4；无可用 → 502
resp = upstream_call(p, m, body)                                // 失败重试 1 次
resp = scan_response(resp)                                      // contains_sensitive 置位
insert("INSERT INTO b_request_logs(...)")                       // 记录 usage 与耗时
accrue_user_quota(auth.user, m.id, resp.usage)                  // 累加 used 字段
return resp
```



#### POST /api/v1/providers/usage — 查询供应商额度（辅助接口）

辅助接口，沿用 `/api/v1` 前缀；鉴权接受网关访问令牌或登录会话。

请求：

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | bigint | 是 | 供应商 ID |

响应：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| quota_5h_remaining | bigint? | 5 小时窗口剩余额度 |
| quota_5h_refreshed_at | datetime? | 5 小时刷新时间 |
| quota_weekly_remaining | bigint? | 周限额剩余额度 |
| quota_weekly_refreshed_at | datetime? | 周刷新时间 |
| quota_monthly_remaining | bigint? | 月限额剩余额度（预留，当前为空） |
| quota_monthly_refreshed_at | datetime? | 月刷新时间 |

执行流程：

```text
if not auth.is_admin and not has_provider_permission(auth.user.id, :id):
    return 3
return query_one("SELECT quota_5h_remaining, quota_5h_refreshed_at,
                         quota_weekly_remaining, quota_weekly_refreshed_at,
                         quota_monthly_remaining, quota_monthly_refreshed_at
                  FROM b_providers WHERE id = :id")     // 不实时调上游
```
